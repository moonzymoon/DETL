# DETL: A Differentiable Event-Level Tuning Layer for Multivariate Time-Series Anomaly Detection

Reference implementation for the paper "From Point Scores to Alarm Events:
A Differentiable Event-Level Tuning Layer for Multivariate Time-Series
Anomaly Detection".

The layer sits **after** an anomaly detector's score stream and tunes the
ISA-18.2 / EEMUA 191 alarm operators (threshold, on-delay timer, off-delay
timer, deadband) directly against event-level KPIs (missed alarms, alarm
lag, chatter, alarm rate) by gradient descent through differentiable
surrogates of those operators. No detector is trained or modified here.

## Layout

```
src/
  common.py        paths, data splits (35/15/50 chronological)
  datasets/        MetroPT3 and Tennessee Eastman (Rieth extended) loaders
  scorers/         unified scorer entry point get_scores(scorer, dataset)
  kpi/panel.py     hard ISA-18.2 / EEMUA 191 KPI panel (evaluation ground truth)
  tuning/          the contribution of the paper:
      soft_ops.py      soft threshold / hysteresis / on-off delays
      hard_ops.py      hard state machine (deployment side + baselines)
      losses.py        event-level loss + constraint surrogates
      constrained.py   Lagrangian trainer with temperature annealing
  experiments/     e1..e8 scripts producing every table and figure
  tests/           unit tests (test_kpi.py, test_tuning.py)
  _score_cache/    cached detector scores for TE and MetroPT3
results/           archived CSV outputs used in the paper (regenerated by the scripts)
```

## Reproduce

```bash
pip install -r src/requirements.txt   # Python 3.11, CPU torch is enough
cd src
python tests/test_kpi.py
python tests/test_tuning.py
python experiments/e1_point_quality.py        # -> ../results/e1/
python experiments/e2_alarm_amplification.py  # -> ../results/e2/
python experiments/e3_baselines.py            # -> ../results/e3/
python experiments/e4_ablation.py             # -> ../results/e4/
python experiments/e5_soft_hard_gap.py        # -> ../results/e5/
python experiments/e6_loss_comparison.py      # -> ../results/e6/
python experiments/e8_transfer.py             # -> ../results/e8/
```

## Data sources

| Dataset | Access |
|---|---|
| Tennessee Eastman (extended, Rieth et al. 2017) | https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/6C3JR1 |
| MetroPT3 | https://archive.ics.uci.edu/dataset/791/metropt3+dataset |
| SWaT | iTrust Centre, SUTD: https://itrust.sutd.edu.sg/ (access agreement) |
| WADI | iTrust Centre, SUTD: https://itrust.sutd.edu.sg/ (access agreement) |
| BATADAL | https://www.batadal.net/ (public; place `BATADAL_training1.csv` / `BATADAL_training2.csv` under `DATA_ROOT/BATADAL/`) — Taormina et al., JWRPM 144(8), 2018 |

Point `DATA_ROOT` at the folder that holds the raw datasets; TE and
MetroPT3 loaders fetch nothing themselves.

**SWaT/WADI scope.** The raw SWaT/WADI files are covered by an iTrust data
access agreement that prohibits redistribution, so neither the raw data nor
detector scores derived from them can be shipped in this repository. The
SWaT/WADI experiments consumed score caches produced by the scorer stack of
our (unpublished) companion project, which imports a private `cadms`
package; those import sites are visible in `src/scorers/adapter.py` and
`src/experiments/train_cmhmil_new.py` and will not run as-is. Everything
else—TE, MetroPT3, and BATADAL end to end, and the tuning layer on any
(score, label, interval) triple—is fully reproducible from this
repository (BATADAL raw data are public; see the table above).
